# Project Polis: Society OS 🏙️

**Project Polis** is a next-generation civic management interface designed for modern societies. It features a dual-mode interaction model combining a spatial map view with a Kanban-based status automaton, allowing residents to report, track, and analyze local issues in real-time.

## ✨ Key Features
- **Spatial Map Interface**: High-fidelity SVG coordinate mapping for hyper-local issue reporting (Targeting Divya Apartment, Mumbai).
- **Kanban Board**: Drag-and-drop workflow management to track issues from "New" to "Resolved".
- **Real-time Analytics**: Built-in telemetry dashboard showing resolution rates, category breakdowns, and hotzone identification.
- **Verified Reporting**: Community-driven upvoting system to highlight urgent needs.
- **Premium Design**: Modern dark-space aesthetic with frosted glass UI and intuitive telemetry cards.

## 🛠️ Tech Stack
- **Framework**: React.js with Vite
- **Icons**: Lucide-React
- **State Management**: Context API
- **Icons/Symbols**: Google Material Symbols
- **Styling**: Vanilla CSS with Modern Glassmorphism

## 📦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Coder9611/society.git
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Run locally**:
   ```bash
   npm run dev
   ```
